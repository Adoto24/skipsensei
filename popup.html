Keyboard Shortcuts

Active on the page whenever a supported player is on screen

  • S

    Skip Intro

    Same as clicking "Skip Intro" — only works once a timing is resolved.

  • M

    Mark Intro End

    Same as clicking "Marquer fin d'intro" — only while no timing has been detected yet.

  • A

    Toggle Auto Skip Intro

    Flips the same Auto Skip Intro switch as the Dashboard and Settings toggles.

Ignored while typing in a text field on the page.
